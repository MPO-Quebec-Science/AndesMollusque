# Convert ANDES UTC time string and converts it to a POSIXct object

Convert ANDES UTC time string and converts it to a POSIXct object

## Usage

``` r
parse_andes_datetime(andes_time_str)
```

## Arguments

- andes_time_str:

  The string representing the datetime from ANDES DB

## Value

POSIXct object representing the time in UTC
