## Usage

``` r
left_join(x, y, ...)
```

## Arguments

- x, :

  the "left" dataframe (all.x=TRUE)

- y, :

  the "right" dataframe

- by, :

  by The name (or names) of the column to merge on, must be in both x
  and y.
