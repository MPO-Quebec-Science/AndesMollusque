# Cleanup text form ANDES to play nice in Oracle

Cleanup text form ANDES to play nice in Oracle

## Usage

``` r
cleanup_text(df, col_name = NULL, max_chars = NULL)
```

## Arguments

- df:

  Dataframe

- col_name:

  String the name of the column to target in the dataframe

- max_chars:

  Numeric, maximum characters allowed in Oracle
